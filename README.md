# Keith Terry Record Collection — shared assets and redirects

The single maintained website is https://peterbonos.com/records/.

Website source and catalog updates belong in `peterbonos-bot/personal-website`, under `records/`. Do not restore or maintain a second storefront here.

This repository continues to serve cover artwork and uploaded record-spine photographs used by the official site. Keep GitHub Pages enabled and preserve these asset URLs. Its `index.html` and `404.html` redirect visitors to the official site.
